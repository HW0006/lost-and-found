# Lost & Found · 失物招領

A tiny bilingual lost-and-found board — one single HTML file, no build step, no server. Open it, pin your own cards.

一個小小的雙語失物招領板 — 只有一個 HTML 檔案，不用安裝、不用伺服器。打開就能用，貼自己的卡片。

**Live site · 線上版：** https://heidi-lost-and-found.netlify.app/

## How it works · 怎麼用

- **I lost it · 我弄丟了** — pin what you lost, where you last saw it, and when.
- **I found it · 我撿到了** — pin something you picked up, waiting for its owner.
- Add an optional photo, mark things found or returned, edit or delete any card.
- Lost items show a "Still missing · 還在找" stamp with a days-missing count.
- First-time visitors see one example card: a lost heart in San Francisco. 💛

## Privacy · 隱私

Your items are saved in **your browser only** (localStorage) — nobody else can see them. Each person who opens the page gets their own board. There is no shared board and no cross-device sync.

你的東西只存在**你自己的瀏覽器**裡（localStorage），別人看不到。每個人打開都有自己的板子。沒有共用的板子，也不會跨裝置同步。

## Run it yourself · 自己跑

Just open `index.html` in a browser — that's it. Or host the file anywhere static (Netlify, GitHub Pages, etc.).

直接用瀏覽器打開 `index.html` 就能用。也可以把它放到任何靜態空間（Netlify、GitHub Pages 等）。
